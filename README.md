# 钢铁前线 · HTML5 坦克大战

一款纯前端实现的坦克大战游戏。使用 HTML5 Canvas 2D 渲染，Web Audio API 合成全部音效与背景音乐，不依赖任何外部框架、图片或音频文件，打开浏览器即可游玩。

## 游戏介绍

游戏包含三种模式：

- **经典战役**：守卫基地，逐关推进。每关 18 辆敌人坦克，基地被摧毁或生命耗尽则失败。
- **极限生存**：无尽波次，敌人数量和强度随波次上升，用 5 点生命值尽可能活得更久。
- **乱斗竞技**：3v3 团队对抗，玩家与两名 AI 队友对阵激进型、狙击型、游击型敌人，180 秒内比分高的一方获胜。

经典战役中的敌人分为四种：

| 敌人 | 特点 | 击毁分数 |
| --- | --- | --- |
| 普通型 | 灰色，速度中等 | 100 |
| 快速型 | 绿色，高速移动 | 200 |
| 装甲型 | 黄色，需 4 发击毁，受击会打退并变色 | 400 |
| 重型 | 红色，高血量，发射三向散弹 | 800 |

击毁敌人后可能掉落道具：

- 星星：火力升级，单发 → 双发 → 散射
- 坦克图标：额外一条命
- 头盔：10 秒无敌
- 炸弹：全屏清敌
- 铲子：基地附近砖墙变钢墙 20 秒
- 时钟：敌人冻结 10 秒

## 操作说明

键盘：

- `W / A / S / D` 或方向键：移动
- `空格`：射击（可按住连发）
- `P` 或 `Esc`：暂停 / 继续
- `Q`：返回主菜单

触屏：

- 左下角虚拟摇杆：移动
- 右下角开火按钮：射击
- 画面右上角暂停按钮：暂停

## 技术栈

- HTML5 Canvas 2D API
- JavaScript（零依赖，无框架、无构建步骤）
- Web Audio API 合成音效与音乐
- LocalStorage 持久化最高分、战绩进度与设置
- CSS 自适应布局，逻辑分辨率 960 × 640

## 皮肤系统

主界面「车库」入口包含 12 款皮肤，按普通、稀有、史诗、传说分级：

- 普通：标准绿（默认）、沙漠迷彩、雪地涂装
- 稀有：红色警报、蓝色闪电、黑曜石、城市迷彩
- 史诗：黄金战神、幽灵坦克、熔岩核心
- 传说：银河幻影、末日审判

皮肤提供速度、护甲、火力、弹速、道具时长、金币获取等属性加成。史诗皮肤拥有专属炮口火焰、粒子拖尾与光环；传说皮肤额外带车身流光、常驻粒子光环和全屏击杀爆炸特效。限时体验卡到期后自动收回，车库中会显示剩余倒计时。

## 经济系统

- 金币：击毁敌人、通关、波次奖励、任务、签到、成就、宝箱均可获得，周末双倍日游戏内金币收益翻倍
- 皮肤碎片：签到、宝箱与已拥有皮肤重复奖励时获得，可在活动中心合成指定皮肤
- 金币独立存储在 `steel_front_coins_v1`，皮肤/任务/签到等元进度存储在 `steel_front_profile_v1`，旧版最高分/进度存档继续保留在 `steel_front_save_v1`
- 结算界面会展示本局获得的金币与当前碎片总量

## 每日签到

主界面「每日签到」按 7 天循环发放奖励：金币、皮肤碎片、限时皮肤体验卡与神秘宝箱。断签后从第 1 天重新开始，累计签到天数会永久保留，并用于成就判定。当天未签到或活动有可领取奖励时，对应入口显示红点。

## 活动系统

- 每日任务：完成对局、击杀、模式进度、使用道具等 6 项任务，每日自动刷新
- 皮肤碎片合成：使用碎片按稀有度价格直接解锁未拥有的皮肤
- 神秘宝箱：消耗宝箱或 1000 金币开启，可随机获得金币、碎片、稀有皮肤或史诗皮肤
- 周末双倍：周六、周日游戏内金币收益翻倍
- 成就：完成首局、百人斩、生存 30 波、集齐 6 款皮肤、签到 30 天、经典通关等 6 项成就，奖励金币或皮肤

## 运行方式

### 方式一：直接打开

双击 `index.html` 即可在 Chrome / Firefox / Edge 最新版中运行。所有脚本均为普通 `<script>` 加载，不依赖本地服务器。

### 方式二：本地服务器

macOS / Linux：

```bash
./start.sh
```

默认端口为 8000，可用 `PORT=8080 ./start.sh` 指定端口。

Windows：

双击 `start.bat`，或执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File server.ps1
```

浏览器打开 `http://localhost:8000`。

## 存档与设置

最高分、经典关卡进度、生存波次、乱斗胜场、累计击毁数与设置项保存在浏览器 `localStorage` 中；金币与皮肤/任务/签到/成就系统使用独立 key 存档，所有字段均带默认值兜底，旧版存档缺失新增字段时会自动补全，不会丢数据。设置面板可调整音效、音乐、震动、粒子密度与高对比模式。

## 性能与兼容

- 固定逻辑分辨率 960 × 640，页面自动缩放适配桌面与移动端
- `requestAnimationFrame` 驱动，目标 60fps
- 碰撞检测、视线检测与粒子系统均针对低端移动设备做了规模控制

## 账户系统与云存档

### Supabase 配置
1. 打开 `config.js`，填写 `SUPABASE_CONFIG`：
```js
SUPABASE_CONFIG: {
  url: "https://YOUR_PROJECT.supabase.co",
  anonKey: "YOUR_ANON_KEY"
}
```
2. 在 Supabase 中创建表 `game_saves`：
```sql
create table public.game_saves (
  user_id uuid primary key references auth.users(id) on delete cascade,
  save_json jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.game_saves enable row level security;
create policy "own save" on public.game_saves
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
```
3. 刷新游戏页面即可注册、登录和云同步。未配置时自动保持纯 LocalStorage 离线模式。

### 玩家操作
- 首次打开会显示欢迎弹窗，可选择注册、登录或游客模式。
- 已登录用户右上角显示头像和邮箱前缀。
- 点击用户区域可手动同步、导出存档或退出登录。
- 金币、皮肤、碎片、签到、任务、成就和战绩都会自动合并同步。

### 同步规则
- 登录后立即拉取云端存档并与本地合并。
- 金币、碎片取最大值，皮肤取并集，签到取最新日期。
- 游戏内数据变化后防抖 2 秒自动同步。
- 页面关闭前尝试最后一次同步。
